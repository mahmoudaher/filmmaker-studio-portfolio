# Filmmaker Studio Portfolio

A modern portfolio website for a filmmaker and visual storyteller. The project presents creative work, project highlights, and an editorial-style browsing experience through a Next.js frontend.

## Highlights

- Responsive portfolio layout
- Media-focused project presentation
- Reusable UI components
- Tailwind CSS styling
- Next.js application structure

## Run Locally

```bash
npm install
npm run dev
```

Open the local URL printed by Next.js in your browser.

## Project Structure

- `app/` contains application routes and pages.
- `components/` contains reusable interface components.
- `data/` contains portfolio content.
- `public/` contains static assets.
